# Credits and provenance

Developed by Daniel Aguilar. Originally created during the University of Georgia Virtual Reality course; this repository is a standalone portfolio edition, not a new implementation of the original project.

Source: [original development repository](https://github.com/da42450/vr-portfolio-project-1), extracted from commit `751e0837db920eddaefa3eb86802f6f9ce9159b8`. The original source repository retains the development history. The standalone edition reorganizes paths, packages its runtime, and updates visitor-facing documentation without changing the core simulation.

The original development workflow used OpenAI's coding agent with GPT-6.1 Sol for implementation, debugging, tests and documentation. Daniel directed the features, operated the demos, supplied the recordings and reported device issues. Automated checks are not a substitute for physical-headset validation.
